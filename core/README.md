# Alpha Core

Alpha Core — технологически независимое архитектурное ядро AlphaLab AI. Оно определяет границы процессов сбора, накопления знаний, оценки, оркестрации, публикации и планирования.

На этапе TASK-0004 пакет содержит только структуру и документацию. Публичные контракты, модели данных, события и исполняемая реализация будут добавляться отдельными Backlog-задачами после архитектурного согласования.

## Модули

- `event_bus/` — доставка событий между модулями ядра;
- `collector/` — прием и первичная нормализация входных данных;
- `knowledge/` — управление проверенным знанием;
- `scoring/` — вычисление и представление оценок;
- `publication/` — подготовка и передача одобренных результатов на публикацию;
- `scheduler/` — формирование временных триггеров;
- `workflow/` — координация многошаговых процессов.

Подробные границы и правила зависимостей описаны в `docs/architecture/alpha-core.md`.
