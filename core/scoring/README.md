# Scoring

`scoring` определяет процесс получения воспроизводимых оценок на основе доступного знания.

## Ответственность

- применение версионируемых правил оценки;
- формирование результата оценки и объясняющих метаданных;
- фиксация версии входных данных и правил;
- публикация событий о рассчитанных или отклоненных оценках.

## Вне ответственности

- сбор исходных данных;
- хранение канонического знания;
- управление расписанием;
- принятие решения о внешней публикации.

Модуль должен получать данные только через утвержденные контракты знания и не обращаться к хранилищам напрямую.
