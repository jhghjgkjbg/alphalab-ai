# Workflow

`workflow` координирует многошаговые процессы Alpha Core без присвоения ответственности отдельных доменных модулей.

## Ответственность

- описание допустимых стадий и переходов процесса;
- реакция на команды, временные триггеры и доменные события;
- координация шагов через публичные порты модулей;
- фиксация состояния, результата и причин остановки workflow.

## Вне ответственности

- реализация сбора, знания, scoring или публикации;
- прямое обращение к инфраструктуре;
- встраивание логики внешних систем;
- обход публичных контрактов модулей.

Workflow может координировать модули, но не должен импортировать или использовать их внутренние реализации.
