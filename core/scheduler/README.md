# Scheduler

`scheduler` отвечает за представление плановых триггеров Alpha Core.

## Ответственность

- описание расписаний и условий запуска;
- формирование событий наступления запланированного момента;
- предотвращение неоднозначного повторного запуска одного триггера;
- передача управления в `workflow` через утвержденный контракт.

## Вне ответственности

- выполнение доменных операций;
- прямой запуск collector, scoring или publication;
- реализация конкретного планировщика или очереди;
- хранение бизнес-данных.

Модуль сообщает о необходимости запуска, но не оркестрирует сам процесс.
