# In-Memory Event Bus

## Статус

- Backlog-задача: TASK-0007.
- Статус: MVP для одного Python-процесса.
- Внешний брокер: отсутствует.

## Назначение

Event Bus отделяет производителя события от его потребителей. Производитель знает только контракт события и `BaseEventBus`; он не вызывает handlers и repositories напрямую.

## Контракты

```text
Publisher
   |
   | publish(event)
   v
BaseEventBus <|-- InMemoryEventBus
   |
   | dispatch by exact event type
   +----> AsyncHandler A
   +----> AsyncHandler B
```

- `subscribe(event_type, handler)` регистрирует async handler для точного класса события.
- `publish(event)` запускает snapshot подписанных handlers и ждёт их завершения.
- Один event type может иметь любое число handlers.
- Отсутствие подписчиков является допустимым состоянием.

## Обработка ошибок

Каждый handler вызывается в отдельной защитной coroutine. Исключение перехватывается на границе Event Bus и логируется вместе с типом события и именем handler. Другие handlers продолжают выполняться.

MVP не возвращает publisher результат или ошибку отдельного handler. Производитель не должен связывать собственный успех с внутренним результатом конкретного потребителя.

## Жизненный цикл

`InMemoryEventBus` создаётся composition root и передаётся участникам процесса. Глобальный singleton запрещён: он скрывает подписки, загрязняет тесты и связывает независимые процессы.

## Порядок и конкурентность

Handlers одного события запускаются конкурентно. Порядок их завершения не гарантируется. Отдельный `publish()` завершается после окончания всех handlers. Порядок между параллельными вызовами `publish()` также не гарантируется.

## Ограничения MVP

- события не сохраняются;
- доставка только внутри одного процесса;
- нет retry, dead-letter queue и acknowledgement;
- нет гарантии exactly-once;
- нет приоритетов и фильтров подписки;
- нет наследуемой диспетчеризации по базовому классу события.

Эти ограничения нельзя скрытно компенсировать внутри доменных handlers. Переход к внешнему брокеру потребует отдельного адаптера `BaseEventBus` и ADR о семантике доставки.
